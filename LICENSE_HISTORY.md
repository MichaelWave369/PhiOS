# PhiOS License History

This file records the public licensing transition for PhiOS.

## GPLv3 era

The public PhiOS line used the GNU General Public License version 3 through commit:

```text
9e1ab3d209c87bbcfcf86f15fd74d8917d21827b
```

A preserved repository branch points to that exact pre-migration state:

```text
archive/pre-phi-commons-license-2026-09-17
```

Versions already distributed under GPLv3 remain available under the rights that were granted with those versions. Nothing in the later MIT release revokes or narrows those previously granted rights.

## Phi Commons / MIT era

Beginning with the Phi Commons relicensing change, project-owned PhiOS code and documentation are released under the MIT License unless otherwise noted.

Third-party material remains governed by its original license.

## Why preserve both eras?

The project treats licensing history as provenance. A later licensing decision should not rewrite or obscure the terms under which an earlier artifact was published.
