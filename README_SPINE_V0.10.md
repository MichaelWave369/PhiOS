# PhiOS Spine v0.10 - Reality Gate Verification Bridge

Spine v0.10 adds the first bounded Reality Gate verification contract.

It keeps two claims separate:

```text
"The evidence says X."  !=  "X is true in the world."
```

Source-content claims can be checked deterministically against cited text evidence.

World-state claims remain UNRESOLVED until an independent world verifier exists.

Verification requires:

`reality.verify`

See `docs/PHIOS_SPINE_V0.10_REALITY_GATE.md`.
