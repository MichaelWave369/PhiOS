# PhiOS Spine v0.11 - Local Interface World Verifier

Spine v0.11 adds the first direct world-state observation to the Reality Gate.

```text
claim about local interface
        ↓
exact-name host observation
        ↓
content-addressed JSON evidence
        ↓
RealityReceipt
```

It requires both:

`reality.verify`

and:

`reality.local_interface.read`

Generic world-state claims remain unresolved.

See `docs/PHIOS_SPINE_V0.11_LOCAL_INTERFACE_VERIFIER.md`.
