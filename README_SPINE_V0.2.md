# PhiOS Spine v0.2 — Mandala Contract Layer

Spine v0.2 turns the v0.1 action proof into the first typed Mandala transaction.

**Packet → GateReceipt → explicit authority → ActionReceipt → bounded execution → Reality Ledger**

The four gates and status vocabulary are now code-level contracts, and the existing action path is linked to them without breaking the legacy execution receipt.

See `docs/PHIOS_SPINE_V0.2_MANDALA_CONTRACT.md`.
