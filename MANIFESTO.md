# PhiOS Project Principles

PhiOS is open-source software for local-first, authority-aware computing.

The project does not depend on an external manifesto or website.

Its principles are intentionally simple:

- **Sovereign** — the operator remains the authority.
- **Coherent** — claims, evidence, permissions, and actions should agree.
- **Local** — prefer local computation and bounded observation when practical.
- **Free** — project-owned PhiOS code and documentation are released under the repository's open-source license unless otherwise noted.
- **Capability is not authority** — adding a tool does not grant permission to use it.
- **Evidence is not interpretation** — preserve provenance and distinguish native evidence from derived analysis.
- **Claim only what was established** — narrow observations must not be promoted into broad conclusions without additional evidence.

The code, tests, receipts, and current contract documents are the living expression of these principles.
